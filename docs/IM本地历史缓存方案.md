# IM 本地历史缓存方案

## 目标与体验

- Windows、Android、iOS 缓存消息和会话列表；已打开会话补齐最近 30 天，后台优先预取最近使用的会话。
- 会话打开和上滑优先显示本地数据，联网后在后台补齐；离线时标明缓存范围和最后同步时间。
- 离线支持查看已缓存消息及已下载附件；发送、撤回等依赖服务器的操作提示联网，保留草稿。

## 保护现有功能

- 本地数据库按服务器、账号、会话隔离并加密；继续保留现有内存缓存，服务器消息 ID 用于去重和排序。
- 复用现有历史分页、滚动锚点和实时事件处理；联网后同步新消息，并核对撤回、编辑、删除、清空记录和权限变化。
- 本地缓存不自行改变服务端已读状态；预取限制并发，不阻塞正常收发、通知和会话切换。
- Windows 退出程序保留会话；主动退出登录时清除该账号的消息及应用管理的附件缓存，不删除用户主动另存的文件。

## 验收

- 覆盖正常收发、上滑历史、未读数、通知、撤回、编辑、删除、清空、搜索定位和附件打开，确认原有行为。
- 覆盖断网、离线重启、重连补齐、多设备变更、账号切换、权限撤销、预取中断和磁盘空间不足。
- 分阶段启用：先在内部环境验证，再逐步开放；出现问题时可关闭本地缓存并回退到现有网络读取流程。

## 约定

- 最近 30 天是缓存目标；尚未完成预取的会话按实际缓存范围展示。
- 浏览器端暂不纳入第一阶段。离线期间的撤回和权限变化以恢复网络后的核对结果为准。
