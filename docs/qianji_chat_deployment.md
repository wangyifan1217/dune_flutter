# 饕独立对话：接入与验证

新版饕使用 `qianji-go` 的 `/api/v1/qianji/chat`，会话和提问保存在 `qianji_chat_conversation`、`qianji_chat_turn`，不共用小饕历史。`qianji-go` 启动时自动运行迁移 V32 和 V33；部署前应按现有数据库备份和迁移流程检查。业务查询结果不存入历史，读取历史时以当前用户权限重新查询，因此数值可能与当时不同。

## 轻量模型配置

服务端默认复用已有 `TASK_BIND_LLM_BASE_URL` / `TASK_BIND_LLM_API_KEY` 或 `IM_SUMMARY_BASE_URL` / `IM_SUMMARY_API_KEY` 的 DeepSeek 兼容通道，默认模型为 `deepseek-v4-flash`。也可通过 `QIANJI_CHAT_LLM_BASE_URL`、`QIANJI_CHAT_LLM_API_KEY` 和 `QIANJI_CHAT_LLM_MODEL` 单独覆盖；配置独立地址时也必须单独配置对应密钥，避免把共享通道密钥发送到其他地址；显式设置空地址会禁用自动回退。部署脚本仅复用显式配置的摘要通道或 New API，不自动使用 Hermes 地址。需要确认通道有 Flash 模型访问权限；地址和密钥均可用时才启用，模型只接收用户问题并返回受限的板块分类，不接收业务查询结果；明确板块名称时直接使用本地规则。模型超时或不可用时回退到本地规则。不要将密钥写入代码或文档。

## 当前能力和边界

侧栏支持业务板块切换，历史和对话分页，旧版入口保留。新版支持各主要板块的有限统计，部分板块支持明细列表，资金借调支持按结清标记筛选，月结支持明确年月、应收应付及逾期查询；部分统计支持明确年月及有限的上下文追问。模型输出和查询入口均按白名单限制；无法准确识别的姓名、部门、状态及其他筛选条件会提示到原页面，不会忽略条件后返回全量结果。月度舆情、提案审核及尚未接入的具体查询会提示进入原页面。

服务端以用户身份调用既有只读服务，资金流向和月结还会同时检查原始授权和用户当前有效权限；资金借调由原服务按用户当前有效权限校验。历史结果按当前权限重查，权限无法确认时隐藏历史问题。普通查询失败、超时和权限拒绝应分别提示；不支持修改、审批等写操作。

## 发布前验证

1. 在测试环境应用 V32、V33，确认新旧客户端与原有饕页面可用；配置轻量模型后检查模型仅收到问题，不包含业务查询结果。
2. 用两个账号验证新建会话、跨设备读取、超过一页的历史以及跨账号访问被拒绝。对同一账号撤销饕或各业务板块权限后，验证历史重读和新查询不暴露失权数据。
3. 覆盖各板块的快捷问题、指定年月、列表、支持的追问、未支持条件和原页面入口；模拟下游 403、超时、不可用以及账号切换。
4. 用 APP 和宽屏分别验证侧栏展开、收起、新旧切换以及离开页面后重新校验。模型未配置、失败或超时情况下验证规则回退。

本地 `go test ./...` 与 Flutter 页面测试属于代码级验证，不能替代真实数据库、权限服务、模型和客户端的端到端联调。
